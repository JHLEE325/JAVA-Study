## 상속 (Inheritance)

## 1. 자바 상속의 특징

### 상속의 개념
상속(Inheritance)은 기존 클래스의 필드와 메서드를 재사용하여 새로운 클래스를 만드는 객체지향 개념 <br>

자바에서는 `extends` 키워드를 사용
```java
class Parent {
    int a;
}

class Child extends Parent {
    int b;
}
```
Child는 Parent의 필드와 메서드를 상속받음

#### 단일 상속
자바는 클래스에 대해 단일 상속만 허용
```java
class A {}
class B extends A {}  // 가능

class C extends A, B {} // 불가능
```
이유
- 다중 상속 시 Diamond Problem 발생
- 메서드 충돌 문제

#### 모든 클래스는 Object를 상속
자바의 모든 클래스는 암묵적으로 `Object`를 상속
```java
class A {}
// 위는 내부적으로
class A extends Object {}
```

#### 상속은 "is-a 관계"
상속은 is-a 관계를 표현함
```java
// Dog is a Animal
Class Dog extends Animal

// Car is a Engine (X) 이건 안됨
```

#### 생성자는 상속되지 않음
부모 생성자는 상속되지 않지만, 자식 생성자에서 호출됨

<br>

### 상속의 장점, 단점
#### 상속의 장점
1. 코드의 재사용성
2. 유지보수성 증가
3. 다형성 구현 기반

#### 상속의 단점
1. 클래스 결합도 증가
2. 변경 전파 가능성
3. 잘못 설계 시 구조가 경직

## 2. super 키워드

### super 키워드란
`super`는 부모 클래스의 멤버에 접근할 때 사용하는 키워드 <br>
부모의 필드에 접근하는 경우
```java
class A {
    int x = 10;
}

class B extends A {
    int x = 20;

    void print() {
        System.out.println(super.x);
    }
}
// 출력 = 10
```
부모의 메서드를 호출하는 경우
```java
class A {
    void hello() {
        System.out.println("A");
    }
}

class B extends A {
    void hello() {
        super.hello();
        System.out.println("B");
    }
}
// B의 hello를 호출하면 super.hello()로 A의 hello도 호출됨
```
부모의 생성자를 호출하는 경우
```java
class A {
    A() {
        System.out.println("A constructor");
    }
}

class B extends A {
    B() {
        super();
    }
}
```
특징
- 생성자 첫 줄에서만 호출 가능
- 생략 시 자동 호출

## 3. 메소드 오버라이딩 (Method Overriding)

### 메소드 오버라이딩이란
자식 클래스가 부모 클래스의 메서드를 재정의하는 것
```java
class Animal {
    void sound() {
        System.out.println("animal");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("bark");
    }
}
// Animal의 sound 메서드를 Dog에서 재정의함
```

### 오버라이딩 규칙
1. 메서드 이름 동일
2. 매개변수 동일
3. 반환 타입 동일 또는 공변 타입
4. 접근제어자 축소 불가 - public이면 public으로만, protected면 protected&public
5. static 메서드는 오버라이딩 불가능

## 4. Dynamic Method Dispatch

### 개념
Dynamic Method Dispatch는 런타임에 실제 객체 타입을 기준으로 메서드를 결정하는 것 <br>
즉 다형성(polymorphism)의 핵심 메커니즘 <br>
예시
```java
class A {
    void print() {
        System.out.println("A");
    }
}

class B extends A {
    void print() {
        System.out.println("B");
    }
}

A obj = new B();
obj.print();

// 출력 B
```
이유 : 컴파일 시 타입은 A이나 new B()로 인해 런타임 객체는 B이기 때문에 JVM이 실제 객체 타입을 기준으로 메서드를 호출

#### 특징
- 오버라이딩된 메서드에서만 적용
- 런타임 바인딩
- 다형성 구현 핵심

## 5. 추상 클래스 (Abstract Class)

### 추상 클래스란
추상 클래스는 객체 생성이 불가능한 클래스
```java
abstract class Animal {
    abstract void sound();
}

class Dog extends Animal {
    void sound() {
        System.out.println("bark");
    }
}
```

#### 특징
- 객체 생성 불가
- 추상 메서드 포함 가능
- 일반 메서드 포함 가능

### 추상 클래스 vs 인터페이스
| 구분  | 추상 클래스 | 인터페이스      |
| --- | ------ | ---------- |
| 상속  | 단일     | 다중         |
| 필드  | 가능     | 상수만        |
| 메서드 | 구현 가능  | default 가능 |

## 6. final 키워드

### final 키워드의 개념
final 키워드가 붙으면 상속, 오버라이딩, 재할당이 불가능해진다
```java
final class A {}
class A {
    final void test() {}
}
final int x = 10;
```

## 7. Object 클래스

### Object 클래스 개념
`java.lang.Object`는 모든 클래스의 최상위 부모

### 주요 메서드
| 메서드      | 설명     |
| -------- | ------ |
| toString | 문자열 표현 |
| equals   | 객체 비교  |
| hashCode | 해시값    |
| getClass | 클래스 정보 |
| clone    | 객체 복사  |
| wait     | 스레드 대기 |
| notify   | 스레드 깨움 |
