## Enum

## 1. enum 정의하는 방법

### enum이란?
`enum`은 서로 관련된 상수들을 하나의 타입으로 정의하는 특수한 클래스
- 단순상수(`int`, `String`)의 단점을 보완
- 타입 안정성 + 가독성 + 유지보수성 확보
- 내부적으로는 `java.lang.Enum`을 상속하는 클래스
- enum도 결국 클래스이며 레퍼런스 타입

### 기본 정의 방법
```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

Day d = Day.MONDAY;
```
특징
- 각 상수는 enum 타입의 인스턴스
- 자동으로 `public static final`이 붙음

### enum vs 기존 상수 방식
#### 기존 방식
```java
public static final int MONDAY = 1;
public static final int TUESDAY = 2;

if (day == 1) // 가독성이 안좋음
```
문제점
- 타입 안정성이 없음
- 값 충돌 가능
- 의미가 불명확함

#### enum 방식
```java
if (day == Day.MONDAY)
// 무슨 요일에 해야하는지 한눈에 파악 가능
```
장점
- 타입 안정성 보장
- IDE 자동완성
- 의미가 명확

### enum은 클래스이다
```java
public enum Grade {
    GOLD, SILVER, BRONZE
}

// 컴파일 시 내부적으로는 아래와 유사

public final class Grade extends Enum<Grade> {
    public static final Grade GOLD = new Grade();
    public static final Grade SILVER = new Grade();
    public static final Grade BRONZE = new Grade();
}
```

핵심 특징
- `new`로 생성 불가
- 생성자는 `private`
- 상속불가 (`final`)
- 모든 enum은 싱글톤 인스턴스

### 필드와 생성자 추가
enum은 단순 상수뿐 아니라 상태를 가질 수도 있음
```java
public enum Grade {
    GOLD(3), SILVER(2), BRONZE(1);

    private final int level;

    Grade(int level) {
        this.level = level;
    }

    public int getLevel() {
        return level;
    }
}
```
사용하는 경우
```java
Grade g = Grade.GOLD;
g.getLevel(); // 3
```

### 메서드 추가 기능
```java
public enum Operation {
    PLUS {
        public int apply(int a, int b) { return a + b; }
    },
    MINUS {
        public int apply(int a, int b) { return a - b; }
    };

    public abstract int apply(int a, int b);
}
```
enum은 추상메서드 + 구현 도 가능

### enum을 사용하는 핵심 이유
1. 타입 안정성 - 다른 값 들어갈 수 없음
2. 가독성 - 코드의 의미가 명확해짐
3. 유지보수성 - 값 변경 시 영향이 적고, 컴파일 타임 오류로 조기 발견 가능
4. 기능 확장 가능 - 필드, 메서드, 인터페이스 구현 가능

## 2. enum이 제공하는 메소드
enum은 내부적으로 `java.lang.Enum`을 상속받으며, 컴파일 시 자동으로 몇 가지 메서드가 생성됨
> 대표적으로 `values()`, `valueOf(String name)`

### values()
```java
public static E[] values();
// enum에 정의된 모든 상수를 배열 형태로 반환
```
사용 예시
```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY
}

for (Day d : Day.values()) {
    System.out.println(d);
}
```
출력
```
MONDAY
TUESDAY
WEDNESDAY
```
특징
- 선언된 순서대로 반환
- 내부적으로 배열 복사본 반환 - 원본을 직접 수정할 수 없음

#### 내부 동작 방식
컴파일 시 enum은 아래 코드를 자동으로 생성함
```java
private static final Day[] $VALUES;

public static Day[] values() {
    return $VALUES.clone();
}
```
clone() 으로 복사본을 반환하는 것

### valueOf(String name)
```java
public static E valueOf(String name);
// 문자열을 enum 상수로 변환
```
사용 예시
```java
Day d = Day.valueOf("MONDAY");
System.out.println(d); // MONDAY

Day.valueOf("monday"); // 예외 발생 - 대소문자를 구분함
```

### values() vs valueOf()
| 메서드       | 역할            |
| --------- | ------------- |
| values()  | 모든 enum 상수 조회 |
| valueOf() | 문자열 → enum 변환 |

### 추가로 알아둘만한 메서드
#### name()
```java
Day.MONDAY.name(); // "MONDAY"
// enum 상수의 이름 반환
```

#### ordinal()
```java
Day.MONDAY.ordinal(); // 0
// 선언 순서 (index) 반환
```

#### toString()
```java
Day.MONDAY.toString(); // "MONDAY"
// 필요 시 override 가능
```

## 3. java.lang.Enum

### 개념
`java.lang.Enum`은 모든 enum이 자동으로 상속받는 최상위 추상 클래스
```java
public abstract class Enum<E extends Enum<E>>

// 즉 우리가 만든 enum은 사실상

public enum Day { ... }
public final class Day extends Enum<Day> { ... }
```

### java.lang.Enum 핵슴 특징
1. 모든 enum은 Enum을 상속
   - 직접 extends는 못하지만 내부적으로 자동 상속
   - 다른 클래스 상속 불가 (이미 Enum 상속 중)
2. 제네릭 구조
   ```java
   Enum<E extends Enum<E>>
   // 자기 자신 타입을 넘기는 (Self-bounded Type) 구조
   Day extends Enum<Day>
   ```

### Enum이 제공하는 주요 메서드
#### name()
```java
Day.MONDAY.name(); // "MONDAY"
// enum 상수의 이름 반환
```

#### ordinal()
```java
Day.MONDAY.ordinal(); // 0
// 선언 순서 (index) 반환
```

#### toString()
```java
Day.MONDAY.toString(); // "MONDAY"
// 필요 시 override 가능
```

#### compareTo()
```java
Day.MONDAY.compareTo(Day.TUESDAY); // -1
// 순서 기반 비교
```

#### equals()
```java
Day.MONDAY.equals(Day.MONDAY); // true
// 사실상 ==과 동일
```

#### `==` 사용 가능

### Enum의 내부 구조
```java
public abstract class Enum<E extends Enum<E>> {
    private final String name;
    private final int ordinal;

    protected Enum(String name, int ordinal) {
        this.name = name;
        this.ordinal = ordinal;
    }

    public final String name() { return name; }
    public final int ordinal() { return ordinal; }
}
```

### enum이 안전한 이유
1. 생성자가 private이기 때문에 외부에서 생성이 불가능
2. 상수 인스턴스가 고정되어 런타임 중 추가 생성 불가능
3. 직렬화 안정성 - 일반 객체는 역직렬화 시 새로운 객체 생성 가능하지만 enum은 항상 같은 인스턴스 반환

## 4. EnumSet

### EnumSet이란?
`EnumSet`은 enum 타입만을 위한 특수한 Set 구현체
```java
EnumSet<E extends Enum<E>>
// 일반 Set이 아니라 enum 전용으로 최적화된 컬렉션
```

### EnumSet을 사용하는 이유?
기존 방식
```java
Set<Day> set = new HashSet<>();
```
문제
- 메모리 낭비
- 성능 비효율 (해시 연산 필요)

EnumSet 사용하는 경우
```java
EnumSet<Day> set = EnumSet.of(Day.MONDAY, Day.TUESDAY);
```
장점
- 비트 벡터 기반
- 매우 빠른 연산
- 메모리 효율

### 내부 구조
EumSet은 내부적으로 bit vector(비트마스크) 사용하여 비트연산으로 포함 여부를 계산함

### 성능 특징
| 항목       | EnumSet      |
| -------- | ------------ |
| contains | O(1) (비트 연산) |
| add      | O(1)         |
| remove   | O(1)         |
| 메모리      | 매우 적음        |

HashSet보다 훨씬 빠르게 연산 가능

### 생성 방법
#### of()
```java
EnumSet<Day> set = EnumSet.of(Day.MONDAY, Day.TUESDAY);
```

#### allOf()
```java
EnumSet<Day> all = EnumSet.allOf(Day.class);
// 모든 enum 포함시킴
```

#### noneOf()
```java
EnumSet<Day> empty = EnumSet.noneOf(Day.class);
// 빈 set을 만듬
```

#### range()
```java
EnumSet<Day> range = EnumSet.range(Day.MONDAY, Day.FRIDAY);
// 선언 순서 기반 범위로 생성
```

#### copyOf()
```java
EnumSet<Day> copy = EnumSet.copyOf(set);
```

#### 사용 예시
```java
EnumSet<Day> weekend = EnumSet.of(Day.SATURDAY, Day.SUNDAY);

if (weekend.contains(day)) {
    System.out.println("주말");
}
```

### EnumSet vs HashSet
| 항목    | EnumSet    | HashSet    |
| ----- | ---------- | ---------- |
| 성능    | 빠름 (비트 연산) | 상대적으로 느림   |
| 메모리   | 매우 효율적     | 비효율적       |
| 타입 제한 | enum만      | 모든 객체      |
| 내부 구조 | bit vector | hash table |
